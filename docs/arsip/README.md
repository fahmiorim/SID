# Arsip Dokumentasi

Folder ini menyimpan dokumen yang **sudah tidak berlaku**. Isinya dipertahankan
untuk jejak keputusan, bukan untuk dijadikan acuan kerja.

**Jangan memakai dokumen di folder ini untuk menentukan status fitur, prioritas,
scope, atau arsitektur.** Gunakan:

- [`../RENCANA-PERBAIKAN.md`](../RENCANA-PERBAIKAN.md) — rencana & milestone
- [`../KATALOG-FITUR-OPENSID.md`](../KATALOG-FITUR-OPENSID.md) — scope lengkap
- [`../PARITAS-OPENSID.md`](../PARITAS-OPENSID.md) — status implementasi
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) — konvensi teknis

| Dokumen | Digantikan oleh | Alasan |
|---|---|---|
| `MAPPING-RISET-vs-KODE.md` | `../PARITAS-OPENSID.md` | Persentase & status usang |
| `RINGKASAN-PERKEMBANGAN.md` | `../RENCANA-PERBAIKAN.md` | Klaim "selesai" tidak sesuai UI |
| `SISA-GAP.md` | `../RENCANA-PERBAIKAN.md` | Mengklaim P0 selesai padahal belum |
| `REKOMENDASI-SELANJUTNYA.md` | `../RENCANA-PERBAIKAN.md` | Urutan prioritas sudah berubah |
| `LOG-PERKEMBANGAN-2025.md` | `../LOG-PERKEMBANGAN.md` | Log lama, tidak lengkap |
| `PEMETAAN-UX-OPENSID.md` | `../PARITAS-OPENSID.md` | Status kedaluwarsa; detail UX tetap jadi referensi |

File-file ini **sengaja tidak dihapus** karena berguna untuk audit keputusan
lama dan mengetahui mengapa scope/rencana pernah berubah. Menyimpannya di
folder arsip mencegah sejarah tercampur dengan dokumentasi aktif.

Aturan: jangan menambah dokumen baru ke folder ini kecuali benar-benar sudah
digantikan oleh salah satu dokumen otoritatif di atas.
